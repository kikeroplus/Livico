# Livico

WorkingTimer のタイマーと、PC1〜PC3 の負荷・温度を 1 つの画面に出す端末。2 画面目はタイマーの代わりに目覚まし。3・4 画面目はタイマー・目覚ましを選びやすくした設定の画面。
機体は SpeechTest で使ったもの (InfoPanel の `env:speaker` と同じ) で、液晶は横置き 320x240。

- タイマーの動き (プリセット、スタート・一時停止・リセット、残りの割合で色が変わる、終了アラーム、呼び出しで一時停止) は WorkingTimer に合わせた
- PC の表示は InfoPanel の 02 SYSTEMS を低くしたもの。MQTT・アラート・音・描画の部品は InfoPanel から持ってきた
- ComfyUI の状態は各 PC の枠の左に 1 行で出す (RUN 12/30、IDLE など)

## 機体と配線

ESP32-S3-DevKitC-1 N16R8 (Flash 16MB / PSRAM 8MB Octal)。配線は SpeechTest・InfoPanel (speaker) と同じで、`include/config.h` にまとめてある。

| 部品 | S3 の GPIO | 備考 |
|---|---|---|
| 液晶 SCL / SDA / CS / DC / RST | 12 / 11 / 10 / 9 / 8 | ST7789 240x320、BL 端子なし、色反転 true。VCC 3.3V、MISO 未接続 |
| SW1 | 13 | もう片側は GND。内部プルアップで押すと LOW |
| SW2 | 14 | 同上 |
| SW3 | 1 | 同上 |
| MAX98357A BCLK / LRC / DIN | 15 / 16 / 17 | Vin 5V。SD・GAIN は未接続 |

GPIO13 は SPI2 の MISO の決まったピンなので、スイッチの `pinMode` は液晶の `begin` のあとでする。

## 書き込み

```
pio run -t upload
```

書き込みとシリアルモニタは基板の「COM」(UART) 側の USB 端子を使う。COM 番号が決まったら `platformio.ini` に `upload_port` を書く。

## 画面

SW1 長押しで 4 つの画面を順に切り替える (1 → 2 → 3 → 4 → 1)。1・2 画面目の下の段 (PC1〜PC3) は同じ。

### 1 画面目: タイマー

```
┌──────────────────────────────────────────┐
│ 11-01 SUN LOW ●   [1][3][10][25][40][60][90][120] │  日付・音量・接続 / プリセット
│                                                  │
│  18:23 45            25:00   (残り時間)            │
│  (現在時刻、大きな 7 セグ)  ● RUN                     │
│                      END 18:48       TODAY 2     │
│ ■■■■■■■■■■■■■■■■■■■■□□□□□□□□  (タイマーの残りの割合)│
├──────────────────────────────────────────┤
│ PC1 CONDOR     CPU ■■■■□□□  23% 55C               │
│ ONLINE         GPU ■■■■■■■  98% 71C               │  3 台ぶん
│ RUN 12/30      RAM ■■■□□□□  61%                   │
│                VRAM■■■■■□□  10.2/16G              │
└──────────────────────────────────────────┘
```

- 上の段
  - 一番上の行: 日付・曜日、音量 (MUTE は赤)、接続ランプ (緑 = WiFi と MQTT、黄 = WiFi だけ、赤 = WiFi なし)、プリセット
  - 左: 現在時刻を大きく (7 セグ。コロンは 1 秒ごとに点滅) と秒
  - 右: タイマーの残り時間と状態 (READY / RUN / PAUSE / DONE)。動いているときは終わる時刻 (`END 18:48`)、それ以外は選んだ長さ。`TODAY` は今日最後まで終えた回数 (日付が変わると 0)
  - 残り時間・プリセット・棒の色: 残り 50% 以上はシアン → 20% でアンバー → 0% で赤。一時停止中は暗くする。終わったら残り時間と上の段の縁が赤く点滅

### 2 画面目: 目覚まし

```
┌──────────────────────────────────────────┐
│ 11-01 SUN LOW ●                       ALARM ON  │
│                      [6:00][6:30][7:00]          │
│  18:23 45            [7:30][8:00][8:30]          │  起きる時刻の一覧 (選んだものを塗る)
│  (現在時刻)           [9:00][9:30][10:00]         │
│                      [10:30][11:00][11:30]       │
│ WAKE 06:30  IN 12H07M              TIMER 12:34  │
├──────────────────────────────────────────┤
│ (下の段は 1 画面目と同じ)                          │
└──────────────────────────────────────────┘
```

- 起きる時刻は 6:00 から 30 分おきに 12 個 (11:30 まで)。毎日その時刻に鳴る
- 右上は ON (黄) / OFF (灰)。下の行は次に鳴る時刻とあと何時間何分か。右はタイマーが動いていれば残り時間
- 鳴っている間は画面中央に `ALARM 6:30` を点滅して出す。どれかのスイッチで止める。止めなければ 5 分で鳴りやむ
- 目覚ましが鳴ると 2 画面目に、タイマーが終わると 1 画面目に自動で切り替わる (それぞれの設定の画面にいるときはそのまま)
- 目覚ましの音量は SW3 の音量とは別で、いつも MID (`src/main.cpp` の `WAKE_VOLUME`)。寝るときに音を OFF (MUTE) にしていても鳴る

### 3 画面目: タイマーの設定

```
┌──────────────────────────────────────────┐
│ 11-01 SUN LOW ●                       ALARM 6:30 │
│                                                  │
│          18:23 45   (現在時刻、いちばん大きく)       │
│                                                  │
├──────────────────────────────────────────┤
│ 25:00  ● RUN                         END 18:48  │
│                                        TODAY 2  │
│ ■■■■■■■■■■■■■■■■■■■■□□□□□□□□  (タイマーの残りの割合)│
│ [  1  ] [  3  ] [ 10  ] [ 25  ]                  │  プリセット (分)。選んだものを塗る
│ [ 40  ] [ 60  ] [ 90  ] [ 120 ]                  │
└──────────────────────────────────────────┘
```

- PC の段は出さない。現在時刻をいちばん大きく、その下にタイマーの残り時間と状態、プリセットを大きなボタンで出す
- 右上は目覚ましの時刻 (OFF なら `ALARM OFF`)
- 操作は 1 画面目と同じ。終わったら画面の縁が赤く点滅

### 4 画面目: 目覚ましの設定

```
┌──────────────────────────────────────────┐
│ 11-01 SUN LOW ●                      TIMER 12:34 │
│                                                  │
│          18:23 45   (現在時刻、いちばん大きく)       │
│                                                  │
├──────────────────────────────────────────┤
│ ALARM ON                             IN 12H07M  │
│ [ 6:00] [ 6:30] [ 7:00] [ 7:30]                  │  起きる時刻。選んだものを塗る
│ [ 8:00] [ 8:30] [ 9:00] [ 9:30]                  │
│ [10:00] [10:30] [11:00] [11:30]                  │
└──────────────────────────────────────────┘
```

- PC の段は出さない。現在時刻をいちばん大きく、その下に ON / OFF と次に鳴るまで、起きる時刻を大きなボタンで出す
- 右上はタイマーが動いていれば残り時間
- 操作は 2 画面目と同じ

### 下の段 (PC1〜PC3)

  - 左: 名前と愛称、PC の状態 (online / offline / sleep / lost)、ComfyUI の状態
  - 右: CPU・GPU・RAM・VRAM の棒と値。温度は 75℃ で黄、85℃ で赤。sys が 15 秒来なければ `--`

## 操作

| 操作 | 動き |
|---|---|
| SW1 長押し (0.7 秒) | 画面の切り替え (1 → 2 → 3 → 4 → 1) |
| **1 画面目 (タイマー)・3 画面目 (タイマーの設定)** | |
| SW1 | 時間を選ぶ (1・3・10・25・40・60・90・120 分を順に)。動いている間は変わらない |
| SW2 | スタート・一時停止・再開。終わったあとは READY に戻す (アラームも止まる) |
| SW2 長押し (0.7 秒) | リセット |
| **2 画面目 (目覚まし)・4 画面目 (目覚ましの設定)** | |
| SW1 | 起きる時刻を選ぶ (6:00 → 6:30 → … → 11:30 → 6:00)。選ぶと ON になる |
| SW2 | 目覚ましの ON / OFF |
| **どの画面でも** | |
| SW3 | 音量 (HIGH → MID → LOW → OFF の順に回る) |
| 目覚まし・アラート中にどれか | 止める・閉じる (この押下はほかの操作にしない) |
| SW1 を押しながら起動 | 保存した WiFi を消して設定モードにする |

- 選んだ時間・音量・今日の回数・今の画面・起きる時刻と ON / OFF は Preferences (名前空間 `livico`) に保存し、起動し直しても残る。
- 呼び出し (ベルの `ON`) が来たら、動いているタイマーを一時停止する (再開は SW2)。WorkingTimer と同じ。

## 音

| 場面 | 音 |
|---|---|
| 起動 | ドミソド と上がるチャイム |
| タイマーのスタート・再開 | ソ→ド |
| 一時停止・リセット | ド→ソ |
| タイマー終了 | 「ピピピッ」と「じかんに なりました」、そのあと 30 秒まで 1 秒ごとに「ピピピッ」 |
| 目覚まし | ドミソド の短い音と「ろくじ さんじゅっぷんに なりました。 きしょう じかんです」(起きる時刻を読む)。そのあと 2 秒ごとに音、声は 30 秒ごとにくり返す (最長 5 分)。音量はいつも MID |
| ComfyUI のジョブ完了 | 高いミソド (画面の上に通知を 4 秒) |
| アラート (切断・ComfyUI の異常) | 高低の警告音を 3 回 |
| 呼び出しベル | ピン・ポーン のあとに「よびだされました」(20 秒の間 5 秒ごとにくり返す) |
| スイッチ | 短い ちっ という音 |

- アラート・呼び出し・目覚ましの間はタイマー終了のアラームを待たせ、閉じたあとに最初から鳴らす (WorkingTimer と同じ)。
- 大きさは `include/config.h` の `TONE_VOLUME` (音) と `VOICE_VOLUME` (声)。SW3 の音量はこれに掛かる。
- `src/sound_speaker.cpp` は InfoPanel のものにタイマーと目覚ましの音 (SND_START・SND_PAUSE・SND_TIMER・SND_WAKE) を足したもの。
- `src/kanavoice.h` / `kanavoice.cpp` は `..\SpeechTest\src` からそのまま写したもの。ここでは直さず、SpeechTest で直してから写し直す。

## アラート

InfoPanel と同じ条件で、画面中央に点滅して出し、警告音を鳴らす。

- PC の予期せぬ切断 (`online` → `lost`)
- ComfyUI の `error` / `down` / `stalled` への変化
- 呼び出しベル (`doorbell/call/+` の `ON`)。ON から 20 秒は出し続ける

MQTT につないだ (つなぎ直した) 直後に届く値 (retain) は基準値で、アラートにしない。正常 (`online`、`idle`、`run`) に戻ると自動で閉じる。

## WiFi の設定

WorkingTimer・InfoPanel と同じ仕組み (`include/WiFiSetup.h` は同じファイル。直すときはそろえる)。

1. 保存済みの WiFi につながらないと、画面が「WIFI SETUP MODE」になり、AP `Livico-XXXX` (MAC の末尾 4 桁) が立つ。
2. スマホでその AP につなぎ、設定ページ (開かなければ `192.168.4.1`) で SSID・パスワードを選んで保存する。同じページで「Device name」(任意) と「MQTT server」(初期値 `192.168.11.32`、空欄なら MQTT を使わない) も変えられる。
3. 3 分たっても設定しなければ設定モードを終え、オフラインでタイマーとして動く (保存済みの WiFi があれば 30 秒ごとにつなぎ直す)。

ESP32 は 2.4GHz にしかつながらない。

## MQTT

トピックの仕様は WorkingTimer の `MQTT_TOPICS.md` が唯一の正。購読するのは `info/pc/+/status`・`sys`・`comfy` と `doorbell/call/+` で、何も送らない。
クライアント ID は `Livico-XXXX` (設定ポータルの AP 名・ホスト名と同じ)。
呼び出しを 1 つの部屋のベルだけにするなら、`src/main.cpp` の `MQTT_CALL_TOPIC` を `doorbell/call/device3` などにする。
